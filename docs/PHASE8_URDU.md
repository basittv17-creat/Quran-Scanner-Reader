# مرحلہ 8 — لفظ بہ لفظ تلاوت اور ہائی لائٹ

اس مرحلے میں درج ذیل ترقیاتی سورس کوڈ بنایا گیا ہے:

- `WordTimingFormat.kt`: آیت اور لفظ کے اوقات کے لیے سخت آف لائن فارمیٹ؛ ہر فائل اور اصل عربی عبارت کے SHA-256 کی جانچ۔
- `OfflineWordTimingStore.kt`: صارف کی ZIP امپورٹ، خطرناک ZIP ناموں، دہرائی، غلط وقت، غلط آڈیو یا نامکمل قرآن کا محفوظ انکار۔
- `WordHighlightText.kt`: تصدیق شدہ عربی متن کے حروف اور اعراب میں کوئی تبدیلی کیے بغیر موجودہ لفظ کو نمایاں کرنا۔
- `OfflineAyahPlayer.kt`: مکمل آیت کے ساتھ منتخب لفظ کی آڈیو کا حصہ چلانے کا بنیادی انتظام۔
- `RecitationActivity.kt`: مکمل آیت، تلاوت کے ساتھ ہائی لائٹ، اگلا/پچھلا لفظ، منتخب لفظ سننا، آڈیو اور ٹائمنگ ZIP امپورٹ۔
- `tools/build_word_timing_pack.py` اور Kotlin/Python ٹیسٹ۔
- WebView کی سبز/سنہری ڈیزائن اسکرین میں لفظ ہائی لائٹ کا نمونہ۔

**اہم:** اصل تلاوت، لفظی اوقات اور 6,236 آیات ابھی فراہم نہیں ہوئیں۔ اس لیے ان خصوصیات کا مکمل حقیقی مظاہرہ ممکن نہیں۔ غلط، مشکوک یا نامکمل ڈیٹا استعمال نہیں کیا جائے گا۔ Android APK بلڈ بھی نہیں ہوا۔ `docs/PHASE8_WORD_TIMING_FORMAT.md` میں امپورٹ فارمیٹ اور ہدایات ہیں۔
