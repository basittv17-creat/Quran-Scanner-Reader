## Native changes

- `MainActivity.kt` uses the same translated OCR profile names in Settings and Gallery. The gallery processing message states where the image is processed. Candidate references use localized numbers and appear separately from canonical Arabic. The gallery crop screen scrolls, including its full-image and cancel actions. Existing Settings navigation restoration and gallery preview recovery were retained.
- `LiveScanActivity.kt` localizes frame conversion, capture and recognition failures. The scrollable screen keeps controls and candidates reachable. The preview has a center-focus accessibility click and gives a localized announcement when the scan area changes. The full camera image button requires no drag. Preview drags keep their physical coordinate mapping. Automatic scanning stays paused on recreation until explicitly resumed, while manual capture remains available.
- `RecitationActivity.kt` and `audio/OfflineAyahPlayer.kt` use translated recording, timing, import, pack-management and playback feedback. Native single-choice items expose the selected pack. Surah and ayah have persistent labels associated with their inputs. Playback status updates use a polite live region. Verse and word selection can be restored. Confirmation and playback still require a new user action.
- Both string files use positional formats and plural resources for counts. Text from pack metadata is wrapped for bidirectional display. Canonical Arabic is assigned directly to RTL text views. The existing gallery crop description, native privacy resources and manual OCR comparison remain in place. The follow-up commit pluralizes the OCR variant count and passes the already-formatted verse reference to the candidate action.
- `tools/test_native_resources.py` runs through the Phase 8 validation entry point. It checks 166 paired string keys and five paired plural keys, resource types, nonempty values, positional argument types and indices, plural forms and distinct crop/full-image labels in English and Urdu.
